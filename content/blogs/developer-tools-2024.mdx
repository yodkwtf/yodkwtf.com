Every few months someone publishes a "top 50 tools for developers" list. This is not that. These are the tools I genuinely open every day and would reinstall first if I had to wipe my machine.

## Terminal: Warp

I resisted switching from iTerm2 for a long time. Warp changed my mind with two things: block-based output (you can copy a command's entire output as one unit) and inline AI completions that actually understand your history and filesystem.

The session sharing feature has saved me hours in debugging sessions with teammates.

## Editor: VS Code + Vim mode

I'm not a vim purist. I use VS Code with the Vim extension and leverage the best of both: VSCode's ecosystem, extensions, and debugger plus vim's modal editing and text object motions.

Key extensions I'd reinstall first:
- **GitLens** — inline blame and history without leaving the editor
- **Error Lens** — surfaces errors inline rather than at the bottom panel
- **Tailwind CSS IntelliSense** — essential if you write any Tailwind

## API Testing: Bruno

Postman got too heavy and too cloud-dependent. Bruno is open-source, stores collections as plain files in your repo (so they're version-controlled), and has a clean interface. If you haven't tried it, give it 20 minutes.

## Database GUI: TablePlus

Works with Postgres, MySQL, SQLite, Redis, and more. The native app feel and quick filters make it my go-to for quick data inspection during development.

## HTTP Debugging: Proxyman

For intercepting and modifying network requests — especially useful when debugging mobile apps or third-party API calls. Far cleaner than Charles.

## What I Removed

Just as important: things I stopped using. Linear replaced Notion for project tracking. Raycast replaced Alfred. Cleanshot replaced the macOS screenshot tool. Each swap was worth it.

The best tool is the one you don't have to think about.
