## Code

Inline code should look good inside prose: `npm run build`, `useEffect`, and `src/app/page.tsx`.

Code with a filename should show the filename in the code block header:

```tsx
// filename: app/components/StatusBadge.tsx
export function StatusBadge({ active }: { active: boolean }) {
  return (
    <span className={active ? 'text-accent-500' : 'text-ink-muted'}>
      {active ? 'Active' : 'Paused'}
    </span>
  );
}
```

Code without a filename should still get the copy button:

```ts
const posts = ['design-notes', 'release-log', 'mdx-showcase'];

const slugs = posts.map((post) => `/blog/${post}`);
```

Plain multiline code:

With `sh` as the code type (pretty):

```sh
content/
  blogs/
    mdx-components-showcase.mdx
src/
  components/
    mdx/
      MDXComponents.tsx
```

Without `sh` as the code type (ugly):

```
content/
  blogs/
    mdx-components-showcase.mdx
src/
  components/
    mdx/
      MDXComponents.tsx
```
